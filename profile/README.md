# BuzzEdit

> One named BuzzEdit sew file. Finish the rewrite. Leave a note the next person can read.

## Session Card

| Slice | What you do in BuzzEdit | What remains |
|-------|------------------------|--------------|
| Arrival | Open BuzzEdit and name today's sew file | A titled stitch rewrite |
| Focus | Keep only live objects on the BuzzEdit board | A short object view list |
| Check | Read BuzzEdit object view before you rewrite a run | A confirmed embroidery edit |
| Handoff | Mark finished rewrites inside BuzzEdit | A note for the next visit |

## How BuzzEdit Sits

BuzzEdit does not replace the machine, the original punch, or the hoop you already own. It sits beside them as a named sew file for one job: which stitches must be rewritten, which object view still matches, and what the next person should read before the next hoop.

If two people share a sew PC, each keeps a BuzzEdit style of their own. Extra designs wait for their own title instead of crowding the live rewrite.

A first visit should be one short stitch rewrite, then the same BuzzEdit file the next day. That is enough to see if the layout holds.

## Traffic Light

| Signal | On the BuzzEdit board | What you do |
|--------|----------------------|-------------|
| Green | Named file, short live object list | Continue the same rewrite |
| Amber | Two designs mixed in one sew file | Split the set before you edit |
| Red | No title, no note, objects unlabeled | Stop and name the sew file first |
| Clear | Handoff written, live objects few | Close BuzzEdit and leave the hoop |

## Open Order

1. Open the last BuzzEdit sew file, not a new empty object view.
2. Read the object list and the last handoff.
3. Finish one visible stitch rewrite inside BuzzEdit.
4. Write what changed, then close with fewer unlabeled objects than you found.
5. If the set feels crowded, drop anything that belongs to a different BuzzEdit hoop.
6. Confirm BuzzEdit embroidery edit still points at the file you own.
7. Check BuzzEdit object view after each rewrite before you sew.
8. Leave the sew file title on the desk before you close.

## Desk Fit

| Who | What BuzzEdit holds |
|-----|--------------------|
| Sew desk | Stitch rewrite and object view on a file you own |
| Shared desk | One BuzzEdit profile per person |
| Shop edit | Named sew files waiting for the next hoop |
| Archive | Finished rewrites off the live object view |
| Support | A repeatable BuzzEdit layout for the same machine |
| Review bay | Objects checked before the embroidery edit leaves |
| Home hoop | Personal files out of the work sew pile |

## After a Week

A week in BuzzEdit is not a rebuilt design from scratch. It is the same title, a shorter live object list, and a note that still makes sense before the next hoop. Take finished rewrites off the live set so the next visit starts on stitches that still need an edit.

Other programs stay where they are. BuzzEdit only keeps the path back: file name, stitch rewrite, object view, handoff.

Leave BuzzEdit with a quieter sew file than the one you opened. The next visit should start on that rewrite, not on a full rebuild of the design.

## Sign-off

- [ ] The BuzzEdit workspace name is short enough to scan
- [ ] Only live objects are on the board
- [ ] A second person can read the handoff
- [ ] The last BuzzEdit sew file still opens after a restart
- [ ] Finished rewrites are off the live BuzzEdit set
- [ ] The BuzzEdit summary still matches the object view
- [ ] Embroidery edit still points at the file you own
- [ ] Object view was checked after the last stitch rewrite

## Field Note

BuzzEdit is easier to trust when the sew file stays smaller than the design folder it came from. Name the rewrite, keep the live objects, finish one visible stitch pass, and write what changed.

The same loop fits a shop edit, a home hoop, or a shared sew PC. Open the last BuzzEdit sew file and continue. Do not rebuild the whole design from scratch.
